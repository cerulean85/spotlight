# 문서 작성 및 검수 체크리스트

## 문체 및 문장 부호

1. 존댓말(~습니다, ~합니다, ~입니다) 배제 및 평어체 작성 확인
2. 개조식(`*`, `-`, `•`, 번호 목록) 항목의 서술형(~다, ~한다) 종결 배제 및 명사형(~함, ~임) 또는 명사구 종결 확인
3. 개조식 항목 끝 온점(`.`) 표기 생략 확인
4. 줄바꿈 후 하위 목록을 갖는 상위 목록 항목 끝 콜론(`:`) 표기 생략 확인
5. 일반 평서문 종결 시 콜론(`:`) 배제 및 온점(`.`) 종결 확인
6. 수치 및 기간 등 범위('~에서 ~까지') 표기 시 물결표(`~`) 대신 하이픈(`-`) 사용 확인

## 내용 구성 및 서술

1. 배경지식이 낮은 독자를 전제한 전문 용어, 축약어, 수식 기호 설명 및 직관적 인과 관계 서술 확인
2. 사실과 정보 전달 중심의 간결한 서술 및 중복·장황한 표현 배제 확인
3. 제목 및 본문 내 불필요한 수량 수식어('N대 원칙', 'N대 카테고리' 등) 배제 확인
4. 헤더 제목의 요약문 형태 지양 및 대표성을 지닌 간결한 명사구 작성 확인
5. '100% 방지', '100% 차단' 등 절대적·단정적 수치 표현 지양 확인

## 서식 및 마크다운 문법

1. 볼드 서식 적용 시 `**...**` 대신 `<strong>...</strong>` 태그 사용 확인
2. 볼드 서식과 따옴표(`'...'`, `"..."`) 중복 적용 배제 확인
3. 제목, 본문, 목록, 표 내 이모지 및 이모티콘 일체 배제 확인
4. 표(Table) 작성 시 표준 마크다운 표 문법 준수 확인
5. KaTeX 수식 블록 앞뒤 빈 줄 삽입 및 정상 렌더링 확인
6. Mermaid 다이어그램 문법 오류 여부 및 정상 렌더링 확인
